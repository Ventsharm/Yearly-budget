Set up automatic reminders on your phone

Large, simple steps. No zooming around the GitHub code page, no token entered on this website.

What this page can do

Copy the full Google Apps Script with one tap and guide you through the Google setup. Google handles the private authorisation and daily clock.

Privacy: This page never asks for, stores, or sends your GitHub token. Enter it only in Google's private Script properties.
Google's code editor may still zoom on Android. This page cannot embed or change Google's editor. In Chrome, ⋮ → Desktop site and turning your phone sideways may help for the short paste-and-save step.

4

Store the token privately in Google

In Apps Script open Project Settings ⚙ → Script properties → Add script property.

Property name: GITHUB_TOKEN

Property value: Your restricted GitHub token

Press Save script properties.

5

Check GitHub access and approve Google permissions

In the Google editor's function selector choose verifyGitHubAccess, press Run, and approve the Google permissions. The log should say GitHub access OK.

6

Test an automatic real notification check

Choose scheduleOneTimeTest in Google's function selector, then press Run once. This only creates a timer. Google should start the real notification workflow automatically at least two minutes later (sometimes later).

Check for Reminders — apps-script-test in GitHub Actions. It must show workflow_dispatch and not be a dry run.

Check automatic test ↗
This is a real production check. Eligible, unclaimed reminders due tomorrow may send notifications. A green result only proves the GitHub job completed; inspect its log for counts.
7

Enable the 9:30 AM daily timer

After the test succeeds, run enableDailyAt930UK once in Google Apps Script. This installs one daily trigger at approximately 9:30 AM UK time (allow around 15 minutes either way).

Then tell ChatGPT “Google test succeeded” so the old GitHub 9:11 AM fallback can be removed. Until then it stays as backup.
